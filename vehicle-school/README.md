# Водить.РФ — школа вождения речного транспорта

Готовый статический проект для демонстрационного экзамена (вариант В1_КОД 09.02.07-3-2026-ПУ, портал «Водить.РФ»).
Сайт полностью работает без сервера и без базы данных: заявки, пользователи и отзывы хранятся в `localStorage`
браузера (имитация таблиц БД), поэтому все страницы можно открыть двойным кликом по `index.html`.

## Структура

```
vehicle-school/
├── index.html          — главная: направления, шаги обучения, слайдер, отзывы, FAQ
├── login.html          — страница входа (валидация + информативные уведомления)
├── register.html       — регистрация: логин, пароль, ФИО, дата рождения, телефон, e-mail
├── account.html        — личный кабинет: профиль, слайдер, история заявок, отзывы
├── request.html        — оформление заявки: транспорт, дата ДД.ММ.ГГГГ, время, оплата
├── admin.html          — панель администратора: фильтры, поиск, сортировка, пагинация
├── css/style.css       — единственный файл стилей (дизайн-система по брендбуку)
├── js/app.js           — единственный скрипт (хранилище, валидация, слайдер, все страницы)
└── assets/
    ├── fonts/          — Rubik 400/500/700 (woff2, локально)
    └── img/            — фотографии (кроп под нужные пропорции, сжаты в JPEG)
```

## Демо-доступы

| Роль | Логин | Пароль |
|------|-------|--------|
| Курсант | `demo26` | `Demo2026` |
| Администратор | `Admin26` | `Demo20` |

В панели администратора уже есть 13 заявок от 4 клиентов — можно сразу проверить фильтры, сортировку,
постраничную навигацию и смену статусов («Новая» → «Идет обучение» → «Обучение завершено»).

## Что реализовано по заданию

**Модуль 1 — функционал**
- регистрация со всеми обязательными полями и проверкой уникальности логина;
- вход по паре логин–пароль с уведомлениями об ошибках, переходы «Еще не зарегистрированы? Регистрация» и обратно;
- личный кабинет с историей заявок и отзывами;
- отдельная страница заявки: транспорт, дата старта, время, способ оплаты;
- панель администратора (Admin26 / Demo20) со сменой статуса заявок.

**Модуль 2 — дизайн**
- единая палитра брендбука (`#007BFF`, `#4CCFE0`, `#FFFFFF`, `#28A745`, `#6C757D`) и шрифт Rubik (36/24/18/16/12 px);
- слайдер из 4 одинаковых изображений с автопереключением каждые 3 секунды, стрелками, точками и свайпом;
- проверенные состояния полей: подсказки рядом с формой, пароль-метр, маска даты и телефона;
- удобный вывод заявок карточками и статусами, отзыв доступен только после завершения обучения.

**Модуль 3 — адаптивность и микроанимации**
- адаптив от 390×844 до десктопа, мобильное меню, таблица заявок превращается в карточки;
- микроанимации появления (IntersectionObserver), hover-эффекты, тосты, модальные окна;
- оптимизация: изображения сжаты и обрезаны под фактические пропорции, `loading="lazy"`, `width/height`,
  локальные `woff2` с `unicode-range`, один CSS и один JS, поддержка `prefers-reduced-motion`.

## Примечание

Данные хранятся в браузере пользователя. Чтобы вернуть исходное состояние демо-базы, очистите
`localStorage` (DevTools → Application → Local Storage → ключи `voditrf:*`).
