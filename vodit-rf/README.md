# Водить.РФ — школа вождения речного транспорта

Сайт для демонстрационного экзамена (вариант В1_КОД 09.02.07-3-2026-ПУ, портал «Водить.РФ»).
Работает без сервера и без базы данных: пользователи, заявки и отзывы хранятся в `localStorage`
браузера (имитация таблиц БД). Достаточно открыть `index.html`.

## Структура проекта

```
vodit-rf/
├── index.html      — вход + направления, цифры школы, шаги обучения, отзывы, FAQ
├── register.html   — регистрация курсанта
├── account.html    — личный кабинет: профиль, слайдер, заявки, отзывы
├── request.html    — оформление заявки на обучение
├── admin.html      — панель администратора
├── css/
│   └── style.css   — единственный файл стилей (дизайн-система по брендбуку)
├── js/
│   └── app.js      — единственный скрипт (хранилище, валидация, слайдер, страницы)
├── img/            — фотографии, логотипы, favicon
└── fonts/          — Rubik 300/400/500/700 (woff2, локально)
```

## Демо-доступы

| Роль | Логин | Пароль |
|------|-------|--------|
| Курсант | `demo26` | `Demo2026` |
| Администратор | `Admin26` | `Demo20` |

В базе 13 заявок от 4 клиентов — можно сразу проверить фильтры, поиск, сортировку и пагинацию.

## Что реализовано по заданию

**Модуль 1 — функционал**
- регистрация со всеми обязательными полями и проверкой уникальности логина;
- вход по логину и паролю с информативными уведомлениями, переходы «Еще не зарегистрированы? Регистрация» и обратно;
- личный кабинет с историей заявок и отзывами;
- отдельная страница заявки: транспорт, дата старта, время, способ оплаты;
- панель администратора (Admin26 / Demo20) со сменой статусов «Новая» → «Идет обучение» → «Обучение завершено».

**Модуль 2 — дизайн**
- палитра брендбука `#007BFF · #4CCFE0 · #FFFFFF · #28A745 · #6C757D`, шрифт Rubik 36/24/18/16/12 px;
- слайдер из 4 одинаковых изображений с автопереключением каждые 3 секунды, стрелками, точками и свайпом;
- подсказки рядом с полями, индикатор надёжности пароля, маски даты и телефона;
- отзыв доступен только после завершения обучения.

**Модуль 3 — адаптивность и микроанимации**
- адаптив от 390×844 до широких экранов, мобильное меню, таблица заявок превращается в карточки;
- анимация появления секций, счётчики цифр, hover-эффекты, тосты, модальные окна;
- оптимизация: обрезанные и сжатые фото, `loading="lazy"`, `width/height`, локальные woff2,
  один CSS и один JS, поддержка `prefers-reduced-motion`.

## Сброс демо-данных

Очистите `localStorage` (DevTools → Application → Local Storage → ключи `voditrf:*`) — база
пересоздастся с демо-данными.
